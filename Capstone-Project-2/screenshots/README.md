# Screenshots

This directory contains screenshots for the README documentation.

## Required Screenshots

To complete the documentation, please add the following screenshots by running the application:

1. **01_initial_screen.png** - Initial application screen with instructions
2. **02_recording.png** - Recording audio input
3. **03_transcript.png** - Whisper transcription result
4. **04_enhanced_prompt.png** - GPT-4 enhanced prompt
5. **05_generated_image.png** - DALL-E 3 generated image
6. **06_console_logs.png** - Console logs showing pipeline steps

## How to Take Screenshots

1. Run the application:
   ```bash
   streamlit run app.py
   ```

2. Follow the workflow:
   - Take screenshot of initial screen
   - Record a voice message (e.g., "a sunset over mountains")
   - Take screenshots at each stage
   - Expand console logs and take final screenshot

3. Save screenshots in this directory with the names listed above

4. Screenshots will automatically appear in the README.md

## Screenshot Guidelines

- Use a clean browser window (hide bookmarks bar)
- Full window capture preferred
- Ensure text is readable
- Show the complete workflow from start to finish
