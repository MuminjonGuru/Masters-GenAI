# 🎤 Audio Recording Guide

Quick guide to recording audio for the Voice to Image Generator.

## 🖥️ Windows

### Option 1: Voice Recorder (Built-in)
1. Press `Windows + S` and search for "Voice Recorder"
2. Click the microphone button to start recording
3. Speak your image description clearly
4. Click stop when done
5. Right-click the recording → "Open file location"
6. Upload the `.m4a` file to the app

### Option 2: Sound Recorder (Older Windows)
1. Press `Windows + R`, type `soundrecorder`, press Enter
2. Click "Start Recording"
3. Speak your description
4. Click "Stop Recording"
5. Save as `.wav` file
6. Upload to the app

---

## 🍎 macOS

### Option 1: QuickTime Player
1. Open QuickTime Player
2. File → New Audio Recording
3. Click the red record button
4. Speak your description
5. Click stop when done
6. File → Save
7. Upload the `.m4a` file to the app

### Option 2: Voice Memos
1. Open Voice Memos app
2. Click the red record button
3. Speak your description
4. Click stop
5. Right-click → Export to Files
6. Upload to the app

---

## 📱 Mobile (iOS/Android)

### iPhone
1. Open Voice Memos app

3. Speak your description
4. Tap stop

### Android
1. Open Voice Recorder or Sound Recorder app
2. Tap record button

## 🌐 Online (Any Device)

### Option 1: Online Voice Recorder
1. Visit https://online-voice-recorder.com
2. Click "Enable Microphone" (allow browser permission)
3. Click red record button
4. Speak your description
5. Click stop
6. Click "Save" → Download as MP3
7. Upload to the app

### Option 2: Vocaroo
1. Visit https://vocaroo.com
2. Click "Click to Record"
3. Allow microphone access
4. Speak your description
5. Click "Stop"
6. Click "Download" → Save as MP3
7. Upload to the app

---

## 💡 Recording Tips

### For Best Results:
- ✅ **Quiet environment** - Minimize background noise
- ✅ **Clear speech** - Speak at normal pace
- ✅ **Close to mic** - Stay 6-12 inches from microphone
- ✅ **Short and clear** - 5-30 seconds is ideal
- ✅ **Avoid echo** - Record in a room with soft surfaces

### What to Say:
Good examples:
- "A sunset over mountains with a lake"
- "A futuristic city at night with neon lights"
- "A cat sitting on a red couch"
- "An astronaut walking on Mars"

Avoid:
- Very long descriptions (keep under 30 seconds)
- Mumbling or unclear speech
- Too much background noise
- Very quiet or very loud volume

## 📊 Supported Audio Formats

The app accepts:
- ✅ WAV (`.wav`) - Best quality, larger file
- ✅ MP3 (`.mp3`) - Good quality, smaller file
- ✅ M4A (`.m4a`) - Apple format (iPhone/Mac)
- ✅ OGG (`.ogg`) - Open format
- ✅ FLAC (`.flac`) - Lossless quality
- ✅ WEBM (`.webm`) - Web format

**File size limit:** 25MB (Whisper API limit)

---

## 🔧 Converting Audio Formats

If your file isn't in a supported format:

### Online Converter (Easiest)
1. Visit https://cloudconvert.com/audio-converter
2. Upload your audio file
3. Select "Convert to MP3"
4. Download converted file
5. Upload to the app

### VLC Media Player (Free Software)
1. Open VLC Media Player
2. Media → Convert/Save
3. Add your audio file
4. Choose MP3 format
5. Click "Start"
6. Upload converted file to the app

## ❓ Troubleshooting

### "Microphone not working"
- Check browser/app permissions
- Try a different recording app
- Test microphone in system settings

### "File won't upload"
- Check file size (must be under 25MB)
- Verify file format (WAV, MP3, M4A, etc.)
- Try converting to MP3

### "Audio quality is poor"
- Record in a quieter environment
- Speak closer to microphone
- Increase recording quality in app settings

---

## 🎯 Quick Test

**Before uploading to the app:**

1. Record a 5-second test: "Testing one two three"
2. Play it back - is it clear?
3. Check file size - under 25MB?
4. Verify format - WAV, MP3, or M4A?
5. If yes to all → Ready to upload!
